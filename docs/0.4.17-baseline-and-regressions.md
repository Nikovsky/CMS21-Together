# CMS21 Together Community Edition — 0.4.17 baseline and regression plan

**Status:** not yet compiled or runtime-tested on the 0.4.17 community branch.

## Branch strategy

- Development base: `community/0.4.17`, branched from `MainMod` (0.4.17).
- Reference only: `community/0.4.16hf3`; do not merge its entire tree or packet protocol.
- UI-001: draft PR #4 into `community/0.4.17`.
- UI-002: draft PR #5 stacked on PR #4; retarget after #4 is merged.
- `MainMod` remains unchanged.
- The repository currently has GitHub Issues disabled (API 410, October 24, 2026). Use this document to track work until Issues are enabled.

## Known facts from source inspection

- Classic C# `.csproj` targeting .NET Framework 4.7.2, x64, explicit `Compile` includes.
- Dependencies referenced from `Libs/`: game/Unity assemblies, MelonLoader, Harmony and other libraries.
- `MainMod.cs` identifies base as 0.4.17; `community/0.4.16hf3` identifies 0.4.16hf3.
- The protocol in `Shared/PacketTypes.cs` differs substantially between branches, including added `fragmented` and changes in inventory requests. Enum ordinal values have changed. Mixing host/client versions is unsafe.
- 0.4.17 uses `ClientSide/Data/SaveSystem.cs` and `SaveSystemHooks.cs` instead of older `Shared/SavesManager.cs`.
- 0.4.17 uses `InventorySync.cs` and `InventoryFix.cs` rather than the older `Inventory.cs`.
- Steam packet fragmentation is present in 0.4.17 transport code but not in the older branch.

This confirms release defects, not their complete root causes in this fork.
